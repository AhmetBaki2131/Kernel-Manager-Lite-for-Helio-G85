# Kernel Manager Lite

An AI-powered, modern, open-source Kernel Manager for rooted Android devices.

Kernel Manager Lite gives you full control over your device's kernel with a clean and intuitive interface. It allows you to manage CPU, ZRAM, I/O Scheduler, and other kernel settings while providing intelligent optimization suggestions through Google Gemini AI.

> **Note:** Some features depend on your kernel and device. Unsupported options are automatically detected and may be unavailable.

## ✨ Features

* 🤖 Gemini AI-powered device analysis
* ⚡ CPU frequency control
* 🎛️ CPU governor management
* 🧠 ZRAM configuration
* 💾 I/O Scheduler management
* 📊 Real-time system monitoring
* 🌡️ CPU and battery temperature monitoring
* 🔋 Battery optimization suggestions
* 🚀 Performance optimization suggestions
* 📋 Detailed kernel information
* 📂 SysFS Explorer
* 💾 Backup & restore settings
* 🌙 Light & Dark theme
* 🌍 Multi-language support (Work in Progress)

## 📱 Requirements

* Root access (Magisk or compatible)
* Android 10+
* A kernel that exposes the required control nodes

## 🤖 AI Assistant

The built-in Gemini AI can:

* Analyze your device configuration
* Detect performance and battery issues
* Explain kernel settings in simple language
* Recommend safe optimizations
* Apply supported optimizations with user confirmation

## ⚠️ Disclaimer

Kernel modifications may affect your device's stability. Always understand the changes before applying them. The developers are not responsible for any damage or data loss caused by improper configuration.
